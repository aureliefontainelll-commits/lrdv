# Les Rescapés du Verger — site statique

Site prêt à publier sur GitHub Pages.

## Publication sur GitHub Pages
1. Créez un nouveau dépôt GitHub, par exemple `rescapes-du-verger`.
2. Importez tout le contenu de ce dossier à la racine du dépôt.
3. Ouvrez `Settings` > `Pages`.
4. Dans `Build and deployment`, choisissez `Deploy from a branch`.
5. Sélectionnez la branche `main` et le dossier `/root`.
6. Enregistrez. GitHub vous donnera une URL du type :
   `https://votre-compte.github.io/rescapes-du-verger/`

## Important
- Les pages et la navigation fonctionnent immédiatement.
- Le site est responsive (ordinateur, tablette et mobile).
- Les formulaires sont actuellement en mode démonstration : ils affichent une confirmation mais n'envoient pas encore d'e-mail.
- Pour recevoir réellement les formulaires, vous pouvez connecter Formspree, Netlify Forms ou un backend.
- Les maquettes originales fournies sont conservées dans le dossier `maquettes/`.
- Les images du site ont été extraites des maquettes que vous avez fournies.
